사사리사 소개

받아쓰기 앱은 말을 글자로만 바꿉니다. 그 다음 버튼을 누르고, 창을 열고, 검색하는 건 여전히 손으로 해야 하죠.

사사리사는 말하면 그 일을 끝까지 합니다. 자주 하는 일은 맥 안에서 1초 안에, 생각이 필요한 일은 쓰시는 AI(클로드·코덱스 등)가 화면을 보고 처리합니다. 쓸수록 더 빨라집니다.

이름이 곧 부르는 말이에요. 불꽃이 타닥 튀는 소리처럼 짧고 또렷해서, 방 안의 다른 말과 헷갈리지 않고 부르면 바로 깨어납니다. 받침이 없어 누구나 쉽게 부를 수 있어요.

원하는 이름으로, 시리처럼 맞춰요. 처음 깔면 부를 이름과 호칭부터 정하고, 그 이름을 몇 번 따라 말하면 이 맥이 내 목소리를 배워 더 잘 알아들어요.

부르는 법

부르거나, 누르고 말하거나.

이름은 바꿀 수 있어요. 처음 부른 뒤 30초는 이름 없이 이어서 말하면 됩니다.

「사사리사」또는 「헤이 사사리사」

띵 소리가 나면 말하세요. 말이 끝나면 0.9초 안에 움직입니다.

오른쪽 ⌥ 누른 채 말하기

핸디처럼 누른 동안만 듣고, 떼면 바로 실행. 시끄러운 곳에서 가장 정확해요.

「됐어」 · 「멈춰」

대답 중에도 끊을 수 있어요. 스피커로 말하는 중이어도 마이크 가까이에서 말하면 멈춥니다.

빠르기

자주 하는 일은 기다리지 않게.

말이 끝난 뒤 움직이기까지 걸리는 시간(대표 맥에서 잰 값).

바로 하는 명령유튜브·소리·타이머
~1초
한 번 배운 말다음부터 그대로 바로
~1초
선택한 글 바꾸기존댓말·영어·맞춤법
~4초
AI에 묻기화면 보고 판단
~7초

자주 하는 말은 쓸수록 「바로」 쪽으로 옮겨 갑니다.

안전

영상 속 목소리가 내 맥을 움직이면 안 되니까. 되돌릴 수 없는 일은 꼭 물어보고, 목소리는 맥 밖으로 나가지 않습니다.

사사리사「보내기」를 누를까요?
응아니
보내기·결제·삭제는 꼭 물어요. 바로 실행 모드에서도 되돌릴 수 없는 일은 「응」을 들어야 누릅니다.
맥 안에서만깨우는 말 · 받아쓰기
외부 전송 없음
목소리는 맥 밖으로 안 나가요. 듣기와 받아쓰기는 맥 안에서 하고, 고르신 AI에 넘기는 글자만 나갑니다(맥 안 모델이면 그것도 안 나가요).
통화 중 · 잠시 쉼줌 · 페이스타임 · 핸디가 마이크를 쓰는 동안
통화 중엔 알아서 쉬어요. 회의 소리를 명령으로 듣지 않게, 다른 앱이 마이크를 쓰면 멈췄다가 다시 듣습니다.

쓰시는 AI 그대로.
입코딩의 끝.

  • 쓰시는 구독 그대로클로드 코드(Claude)·코덱스(ChatGPT)·Aside 중 하나에 한 번 로그인하면 끝. API 열쇠는 필요 없어요.
  • 정해진 도구만 쓰는 안전 모드파일 삭제·아무 명령 실행·터미널 조작은 막혀 있어요.
  • 고사양 맥이면 조합으로웹 심부름은 Aside, 코딩은 클로드 코드, 나머지는 코덱스가 나눠 맡아요. 이것도 무료.
  • API 키·맥 안 모델도OpenAI·Gemini·Anthropic API, 맥 안에서 도는 무료 모델(Ollama·LM Studio)도 같은 안전장치로.
● 듣는 중「클로드한테 로그인 버그 고치라고 해」
설치

10분이면 됩니다.

애플 실리콘 맥(M1 이상) · macOS 14 이상 · AI 하나 (클로드·ChatGPT 구독, API 키, 또는 맥 안 무료 모델)

1

쓰실 AI 하나 연결

클로드 코드(Claude 구독)나 코덱스(ChatGPT 구독)를 깔고 터미널에서 「claude」 또는 「codex」를 한 번 실행해 로그인. Aside·API 키·맥 안 무료 모델은 설정 → 두뇌에서 고르면 돼요.

2

사사리사 설치

터미널에 한 줄 — 또는 위의 「macOS용 다운로드」(애플 공증 완료).

brew install --cask mvcompany8500-web/tap/sasarisa
3

처음 뜨는 준비 화면에서 빨간 칸만

마이크·음성 인식·손쉬운 사용 허용, 정확한 받아쓰기 모델 「받기」. 메뉴 막대에 ◉ 가 보이면 끝 — 「사사리사」라고 불러 보세요.

윈도우는 나중에 나와요. 맥에서 먼저 공개하고, 윈도우판은 듣기·받아쓰기 속도를 맥만큼 맞춘 뒤 따로 출시합니다.
